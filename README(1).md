# THC_Bone

Analysis code associated with a study investigating how Δ9-tetrahydrocannabinol (THC) alters femoral and calvarial bone marrow at single-cell resolution.

## Overview

This repository contains code used for:

- Single-cell RNA sequencing analysis
- Cell type annotation and cell-cycle analysis
- Differential expression and gene set enrichment analysis
- Trajectory and pseudotime analysis
- Differentiation potential analysis
- Cell-cell communication analysis
- Myeloid subclustering and interferon-associated analysis
- Figure generation for manuscript preparation

The study compares femoral and calvarial bone marrow from vehicle- and THC-treated mice to identify tissue-specific cellular, transcriptional, developmental, and intercellular signaling responses to THC.

## Experimental Design

Mouse strain:

- C57BL/6

THC exposure protocol:

- 30 mg/kg Δ9-THC or vehicle
- Intraperitoneal administration once daily
- 10 consecutive days
- Femoral and calvarial bone marrow collected on day 10

Single-cell RNA-seq groups included:

- Femoral Vehicle (fVEH)
- Femoral THC (fTHC)
- Calvarial Vehicle (cVEH)
- Calvarial THC (cTHC)

Each single-cell RNA-seq library was generated by pooling bone marrow from two mice within each tissue and treatment group.

## Repository Structure

```text
01_preprocessing_annotation_with_cluster_colors.Rmd
02_cell_cycle.Rmd
03_femoral_DEG_GSEA.Rmd
04_calvarial_DEG_GSEA.Rmd
05_monocle3_cytotrace2.Rmd
06_cellchat_femoral_v2.1.2.Rmd
07_cellchat_calvarial_v2.1.2.Rmd
08_myeloid_analysis.Rmd
```

`01_preprocessing_annotation_with_cluster_colors.Rmd` documents the primary single-cell RNA-seq analysis workflow, including Cell Ranger matrix import, Seurat object creation, quality control, normalization, integration, dimensional reduction, clustering, cell-type annotation, cluster marker analysis, cell-type composition analysis, and manuscript visualizations.

`02_cell_cycle.Rmd` performs cell-cycle scoring using Seurat S- and G2/M-phase gene sets converted to mouse orthologs with gprofiler2 and generates cell-cycle visualizations.

`03_femoral_DEG_GSEA.Rmd` contains femoral bone marrow composition analysis, THC-versus-vehicle differential expression analysis, volcano plot generation, and Hallmark gene set enrichment analysis.

`04_calvarial_DEG_GSEA.Rmd` contains calvarial bone marrow composition analysis, THC-versus-vehicle differential expression analysis, volcano plot generation, and Hallmark gene set enrichment analysis.

`05_monocle3_cytotrace2.Rmd` performs Monocle3 trajectory and pseudotime analysis and CytoTRACE2 differentiation-potential analysis separately for femoral and calvarial bone marrow.

`06_cellchat_femoral_v2.1.2.Rmd` performs CellChat analysis of femoral vehicle and THC samples, including comparison of interaction number and strength, signaling roles, and incoming and outgoing communication patterns.

`07_cellchat_calvarial_v2.1.2.Rmd` performs CellChat analysis of calvarial vehicle and THC samples, including comparison of interaction number and strength, signaling roles, and incoming and outgoing communication patterns.

`08_myeloid_analysis.Rmd` contains myeloid subclustering and annotation, femoral and calvarial myeloid differential expression and Hallmark gene set enrichment analyses, and interferon-associated gene expression and module-score analyses.

## Data Availability

Raw sequencing data and Cell Ranger outputs are available through the Gene Expression Omnibus under accession number **GSE344219**.

Available data include raw FASTQ files and Cell Ranger filtered feature-barcode matrix files.

Large sequencing files are intentionally excluded from this GitHub repository and should be downloaded directly from GEO.

## Software Requirements

Analysis was performed in R 4.4.1.

Primary packages used include:

```r
library(Seurat)
library(dplyr)
library(tidyr)
library(ggplot2)
library(patchwork)
library(gprofiler2)
library(SeuratWrappers)
library(monocle3)
library(CytoTRACE2)
library(fgsea)
library(msigdbr)
library(CellChat)
library(ComplexHeatmap)
library(NMF)
library(pheatmap)
library(ggrepel)
```

Key analysis package versions include Seurat v5.3.0, gprofiler2 v0.2.3, Monocle3 v1.4.28, CytoTRACE2 v1.1.0, CellChat v2.1.2, fgsea v1.32.4, and msigdbr v25.1.0.

Raw sequencing data were processed using Cell Ranger v3.1.0 and aligned to the mm10 reference genome.

Additional package dependencies may be required for specific downstream analyses or visualization steps.
